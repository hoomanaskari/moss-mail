# Security

Moss handles your email, your passwords and your sign-ins, so security problems matter a lot. Thank you for looking.

## Reporting a problem

Please report it privately, not in a public issue:

1. Go to the [Security tab](https://github.com/hoomanaskari/moss-mail/security) of this repository.
2. Choose **Report a vulnerability**.
3. Say what you found, how to reproduce it, and what someone could do with it.

You'll get an answer within a week. Once it's fixed, the release notes will thank you by name, unless you'd rather stay anonymous.

## What counts

For example:

- Email content that runs code, or reaches the app outside its sandboxed view.
- Passwords, tokens or API keys leaving the macOS Keychain, or showing up in logs or files.
- Mail, or anything about you, sent somewhere it shouldn't go.
- A way to make Moss install an update that wasn't signed with Moss's update key.

## Versions

Only the newest release gets security fixes. Moss updates itself, so most people are on it within hours.
