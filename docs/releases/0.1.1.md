Updates you can see and start yourself.

- **Check for Updates.** Choose Moss, then Check for Updates…, to look for a new version at any time. Moss always answers: it is up to date, a new version is ready with what's new in it, or why it couldn't check, with Try again. Settings shows the same button, and when Moss last checked.
- **A new version shows until you install it.** When there is one, Update to Moss and its number appears at the top of every screen. Click it and Moss downloads it, shows how far it is, installs it and restarts. If you are writing an email, it waits for you to choose Restart now, and your drafts are saved first.
